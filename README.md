# Dzainer Marcenaria - Website para Marcenaria Planejada

Um site moderno, responsivo e elegante para a marcenaria Dzainer Marcenaria, especializada em móveis planejados sob medida.

## ✨ Características

- **Design Responsivo**: Funciona perfeitamente em dispositivos móveis, tablets e desktops
- **Interface Moderna**: Cores sóbrias e sofisticadas que transmitem confiança e profissionalismo
- **Logo Personalizada**: Identidade visual tradicional e confiável para a marca
- **Seções Completes**:
  - Hero com chamada para ação
  - Serviços (cozinha planejada, quarto planejado, móveis sob medida)
  - Sobre a empresa
  - Depoimentos de clientes com slider
  - Formulário de orçamento
  - Footer com informações de contato e redes sociais
- **Formulário de Orçamento**: Campos para nome, contato, tipo de móvel, descrição do projeto e prazo de entrega
- **Animações Sutis**: Transições suaves para melhor experiência do usuário
- **Menu Mobile**: Menu hamburguer para navegação em telas menores
- **Slider de Depoimentos**: Rotaciona automaticamente depoimentos de clientes

## 📁 Estrutura do Projeto

## 🛠️ Tecnologias Utilizadas

- HTML5 Semântico
- CSS3 com Flexbox e Grid
- JavaScript Vanilla (sem frameworks)
- Google Fonts (Montserrat e Playfair Display)
- Ícones SVG personalizados

## 🎨 Paleta de Cores

- **Marrom Escuro (#5D4037)**: Cor primária, transmite solidez e tradição
- **Marrom Medio (#8D6E63)**: Cor secundária, utilizada para destaques
- **Cinza Claro (#fafafa, #f5f5f5)**: Fundos neutros
- **Branco (#white)**: Elementos principais e textos
- **Cinza Texto (#333, #555, #666)**: Textos para boa legibilidade

## 📱 Responsividade

O site se adapta a diferentes tamanhos de tela:
- **Desktop (≥992px)**: Layout completo com sidebar
- **Tablet (768px-991px)**: Menu adaptado, conteúdo em uma coluna quando necessário
- **Mobile (<768px)**: Menu hamburguer, todos os conteúdos em uma coluna
- **Mobile pequeno (<480px)**: Ajustes finos em fontes e espaçamentos

## 📝 Como Usar

1. Clone ou baixe este repositório
2. Abra o arquivo `index.html` em qualquer navegador moderno
3. Para publicar online, faça upload de todos os arquivos para seu servidor de hospedagem
4. O formulário está configurado para usar Formspree (substitua `your-form-id` no action do formulário pelo seu ID real do Formspree)

## 🔧 Personalização

- **Logotipo**: O texto "DzainerMarcenaria" pode ser substituído por uma imagem real em `.logo h1` e `.footer-logo h1`
- **Cores**: Modifique as variáveis de cor no início do `style.css` se necessário
- **Conteúdo**: Atualize textos, imagens e dados de acordo com a realidade da empresa
- **Formulário**: Configure o endpoint do Formspree ou outro serviço de coleta de dados
